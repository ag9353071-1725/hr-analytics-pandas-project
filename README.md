# HR Analytics Pandas Project

## 📊 Project Overview
This project analyzes an HR dataset using Python Pandas.  
The goal is to understand employee data and identify patterns related to salary, attrition, and department-wise trends.

---

## 📁 Dataset Information
- Total Records: 3400 employees
- Total Features: 20 columns
- Key Columns: Department, Attrition, Monthly_Income, Job_Role, Age

---

## 🛠 Tools Used
- Python
- Pandas
- Jupyter Notebook

---

## 📌 Key Analysis Performed

### 1. Data Exploration
- Checked dataset structure using `info()` and `describe()`

### 2. Salary Analysis
- Found highest and average salaries
- Identified top 10 highest-paid employees

### 3. Department Analysis
- Calculated average salary by department
- Counted employees per department

### 4. Attrition Analysis
- Found number of employees who left vs stayed
- Analyzed attrition by department using cross-tabulation

---

## 📈 Key Insights
- Sales department has the highest attrition
- IT department has relatively lower attrition
- Salary distribution varies significantly across employees
- Overall attrition rate is high in the dataset
